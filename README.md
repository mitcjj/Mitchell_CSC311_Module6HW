This application takes in information from the user: their first and last names, their email address, their date of birth, and their zip code.  The form keeps track of if the information given is valid based on regex patterns.  If the input does not follow the guidelines given, then a red warning will appear above the field informing the user of what is required.  When all of the information is entered correctly, a previously disabled "Add" button will be enabled, allowing the user to add this information.  The user will then be taken to another page displaying the information, and allowing the user to fill out another form.
